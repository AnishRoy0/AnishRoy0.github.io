VIII. Lung Function Detection

Motivation

Lung function is important to analyze for Cystic Fibrosis (CF) patients. Montioring lung function in CF patients can give insight into the effectiveness of treatements, how well the patient is doing, and more. Creating a mathematical model for lung function in CF patients could be really helpful to show expected behavior of lung function in CF patients.

Goal

This work aims to create a mathematical model for lung function in CF patients. Current methods for mathematically modeling lung function generally assume a gradual decline. However, CF has more randomness than a gradual decline since, at the end of the day, each CF patient has their own different experience with CF. In the mathematical model we propose, we include steady decline, randomness, and short & long term variability.

Results

Our mathematical model accurately modeled results in the short run, but wasn't very accurate for the long run. Obtaining more data to validate and base our model on would be the future directions to improve our model, since there is very limited public data for lung function of CF patients.
